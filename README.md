# 프로젝트 이름
숫자 뱀서라이트 서바이벌 게임

## 한 줄 소개
유니티 엔진으로 만들고 있는 2D 숫자 기반 서바이벌 게임의 프로토타입 입니다.

## 사용한 도구
- (예: Kiro Spec 모드 + Vibe 모드)
- claude opus 5.5, claude fable 5.2

## 주요 기능
플레이어와 적들의 체력은 모두 숫자로 표시됩니다. 별다른 UI는 없습니다. 적을 처치하고 레벨업하고 강해지는 것이 목표인 단순한 게임입니다.


## 프롬프트 기록
워낙 대화가 많아서 기억은 나지 않는데 기획, 디자인을 확정하는 데 매우 공을 들였던 것 같습니다
   
## 막혔던 순간
- 문제: ai가 의도와 다르게 시스템과 디자인을 구상했을 때, 그리고 플레이했는데 재미가 없었을 때, 사운드 / 음악을 어떻게 해야할지 막막할 때
- 게임 기획 부분에서 아이디어가 막혔을 때, 디자인 구성이 애매할 때, 시스템 구현을 어떻게 할지 생각이 안날 때
- 해결: 단순함은 유지하되 재미를 유발할 수 있는 기획을 하려고 노력했다. 기획서를 직접 써보고 구체화한 뒤 어느 점을 보완하면 좋을지 검토해보았다. 디자인을 직접 시안을 만들어 보고 AI와 함께 시안을 평가해 보며 구체화한 뒤 적용했다. 사운드와 음악을 직접 찾거나 녹음한 뒤 다듬어서 적용하였다. 플레이테스트를 아주 많이 해보며 재미가 있는지 검증했다.

## 내가 직접 수정한 부분
- 위치: `파일명` 00번째 줄
- 내용: 초반에는 제가 직접 코드를 적고 수정했지만, ai를 연결하고 나서 속도가 비약적으로 상승했습니다. 스크립트가 워낙 많고 구조가 반쯤 섞여 있어서 제가 직접 수정하진 않고 검토만 했습니다. 

## 회고
- AI가 잘한 것: 게임의 단순한 구성, 기획 구체화, 개발 정확성, 속도
- AI가 틀렸던 것: 기획은 여전히 사람이 잡아 줘야 함. 디테일한 부분은 아직 미흡함. 
- 새로 알게 된 것: 앞으로 바이브코딩을 할 때 프롬프트를 매우 잘 생각해서 신중하게 적어야 한다. 그리고 분야별로 기본 지식이 아주 중요(특히 프로그램 아키텍쳐, 사운드, 디자인, 기획) 하다는 것을 깨달았다.
